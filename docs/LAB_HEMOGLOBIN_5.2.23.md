# FillBARS Card 5.2.23 — гемоглобин в компактном блоке

В главном блоке рядом с оценкой функции почек показан последний доступный лабораторный гемоглобин с единицей г/л. Источник — тот же набор `DS_ANALYSES` из БАРС; при наличии уже открытой таблицы он читается первым. В раскрывающемся разделе видны дата результата и редактируемое числовое поле. Значение г/дл при необходимости переводится в г/л.

Пороги по выбору пользователя: `<75 г/л` — красный, `75–100 г/л` включительно — оранжевый, `>100 г/л` — без подсветки. Это визуальное выделение, а не диагноз, показатель необходимости или автоматическое решение о трансфузии. Отсутствующее значение либо результат без достоверной единицы не окрашивается и не подменяется догадкой.

Раздел «Исходные данные и ручная проверка» остаётся свернутым по умолчанию; в нём находятся все исходные поля, даты и пояснения. Визуальная проверка: блок шириной 402 px, высотой около 187 px.

Контрольные тесты: строка БАРС `Гемоглобин: 129,0 г/л`, конверсия г/дл, пороги 74,9/75/100/100,1 г/л и чтение уже открытой лабораторной таблицы. Пороговые цвета намеренно не называются универсальными границами анемии: [руководство ВОЗ 2024](https://anaemiaalliance.who.int/resources/repository/item/guideline-on-haemoglobin-cutoffs-to-define-anaemia-in-individuals-and-populations).
