# FillBARS 5.2.41 — ВК для паллиативной помощи и КЭК

Добавлены пункты «ВК — паллиативная помощь» и «Заключение и представление на КЭК» в списке бланков. Доступны редактирование, подстановка общих сведений пациента, предпросмотр исходной структуры, печать и скачивание DOCX.

Первый источник содержал шесть заполненных случаев. В переиспользуемом шаблоне сохранена структура одного заключения: реквизиты учреждения, сведения пациента, диагноз с МКБ, жалобы, объективный статус, решение, рекомендации и три члена комиссии. Все исходные персональные данные и клинические решения удалены. Объёмные блоки осмотра заменены одним редактируемым полем. 25 полей; короткий пример занимает одну портретную страницу. Удалена внешняя ссылка Word на шаблон другого компьютера.

Второй источник DOC преобразован через Word в локальную рабочую копию DOCX; исходный DOC сохранён. В бланке 24 поля. Сохранены две альбомные страницы: по два экземпляра заключения на первой и представления на второй. Поля пациента добавлены в существующие пустые строки. Общие значения синхронно повторяются в экземплярах. Фиксированные варианты решения и цели из исходного бланка заменены ручными полями, пустые маркеры списка удалены. Для браузера построены явные две колонки на странице; скачиваемый Word сохраняет исходные колонки и разрывы.

Решения комиссии, функциональные нарушения, нетрудоспособность, МСЭ, прогноз, цель направления и состав комиссии автоматически не определяются. Клинические поля и подписи заполняются после проверки пользователем. Переносы строк поддерживаются в печати и DOCX. При длинном тексте число страниц нужно проверить в предпросмотре.

Проверка: финальный общий прогон — 211 тестов, все прошли. Первый общий параллельный запуск на фоне браузерной проверки дал таймаут в ранее существовавшем тесте дневников; последовательный повтор прошёл полностью. Браузерная проверка новых форм подтвердила ввод, пустые ручные решения, синхронные экземпляры, альбомную геометрию, печать iframe и формирование Word-файлов кнопкой скачивания. Готовые Word-файлы открыты установленным Word и отрисованы: одна страница для короткого паллиативного заключения и две альбомные для КЭК. Пустые и заполненные страницы просмотрены; исходные файлы проверены по SHA-256 и не изменены. Из-за отсутствия LibreOffice использован нативный Word для визуальной проверки.

Сборка шаблонов: scripts/build-commission-templates.py. Исходный DOC предварительно преобразуется Word в tests/artifacts/commission-541/cec-reference.docx. Для печатной разметки blank-palliative.docx и blank-cec.docx экспортируются в filtered HTML, затем упаковываются scripts/build-commission-print-layouts.py. Для работы расширения исходники и Word не требуются.
