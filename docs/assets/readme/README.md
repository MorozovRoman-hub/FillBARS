# Иллюстрации README

hero.svg — исходник баннера, hero.png — его растровая версия для GitHub. Логотип взят из badger.png этого репозитория. version.svg, manifest.svg, license.svg — локальные значки, не зависящие от внешних сервисов.

diaries.png — актуальный интерфейс дневников, полученный через tests/diary-review-qa.js на искусственных данных. labs.png — компактный блок анализа и расчётов из popup.html, с тестовыми значениями и отключённым чтением БАРС. cec.png — печатный бланк КЭК, представление над заключением, на демонстрационных данных из браузерной проверки.

Реальные данные пациентов не использовались. Материалы этой папки предназначены для README и не включаются в пакет расширения.
