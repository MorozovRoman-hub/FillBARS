# Контрольная точка 5.2.15 — печать согласия на операцию

Причина расхождения: кнопка «Печать предпросмотра» печатала упрощённую HTML-перевёрстку документа, а не исходный бланк. Скачиваемый Word-файл не менялся: пользователь подтвердил, что проблема только в печати из браузера.

Теперь печатный вид согласия на операцию состоит из двух неизменённых страниц исходного бланка, полученных из приложенного `.doc` через Word и отрендеренных в 300 dpi. ФИО, год рождения, адрес, отделение и название операции накладываются только на предусмотренные строки первой страницы. Юридический текст, рамки, вторая страница, места для подписей и дат остаются ровно там же, где в образце. Если введённое значение не помещается в отведённую строку, печать блокируется с предупреждением вместо тихого обрезания. Word-выгрузка остаётся редактируемой и без изменений.

Проверка: напечатанный Chrome PDF на синтетических данных имеет ровно две страницы A4; обе страницы визуально сверены с оригиналом. 158/158 автоматических тестов, проверка внедрения в БАРС и состава пакета прошли. Проверочный ZIP `dist/FillBARS-5.2.15-test.zip`: 46 файлов, SHA-256 `7c9cbe5ae740b0b9d1782e5e55b8b64f6b3b6944fa1ab10ed7cbc617fbc60afe`. Тестовая папка `C:\projects\заново барс\FillBARS` обновлена до 5.2.15, побайтово совпадает с пакетом; 44 прежних файла сохранены в `C:\projects\заново барс\backups\FillBARS-before-5.2.15-20260929-104736`.

Для ручной проверки требуется перезагрузить локальное расширение в Яндекс Браузере, открыть «Согласие на операцию», заполнить поля и нажать «Печать бланка». В диалоге печати выбрать A4, масштаб 100%, без колонтитулов браузера.
