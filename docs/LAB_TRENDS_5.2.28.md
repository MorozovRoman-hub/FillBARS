# Динамика анализов — 5.2.28

В блоке «СКФ и анализы» добавлен раскрываемый раздел «Динамика анализов».
Гемоглобин, креатинин и глюкоза показаны отдельными графиками и таблицами
с датой, значением и названием исследования из БАРС.

- Источник — доступный набор DS_ANALYSES активного пациента. Открытая
  лабораторная форма используется без создания дубликата; если её нет,
  штатная временная форма запрашивает последние 100 направлений.
  Интерфейс указывает число загруженных направлений и возможную неполноту истории.
- Для каждого анализа показано до 12 последних датированных результатов.
  График требует два результата; таблица доступна и для одного.
- Единицы приведены к г/л, мкмоль/л и ммоль/л существующими преобразователями.
  Результаты без распознанных единиц не сравниваются.
- Даты проверяются по календарю, сортируются; ось X пропорциональна времени.
  Записи с неизвестной датой показаны отдельно без точки на графике.
- Масштаб каждого графика свой; диапазон подписан. Цвет линии не является
  оценкой нормы. Наведение на точку показывает дату и значение.
- История не сохраняется в хранилище и очищается перед каждым обновлением.
  Ручные правки текущих показателей не создают лабораторные результаты.

Проверки: card-kidney.test.js, card-lab-trends.test.js и lab-trends-popup-qa.js.
Последняя использует только демонстрационные данные без подключения к БАРС.
