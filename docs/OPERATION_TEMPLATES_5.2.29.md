# Шаблоны операций — 5.2.29

Добавлены шесть редактируемых черновиков протокола:

- Лапароскопическая холецистэктомия.
- Геморроидэктомия по Миллигану—Моргану.
- Паховое грыжесечение с пластикой по Лихтенштейну.
- Пупочное грыжесечение с пластикой по Мейо.
- Послеоперационное вентральное грыжесечение с сетчатым имплантатом.
- Бедренное грыжесечение с указанием фактического способа пластики.

В выборе «Шаблон операции» подставляются название и описание вмешательства.
Индивидуальные находки, размеры, сторона, материалы, дренирование и результаты
контроля оставлены для уточнения в квадратных скобках. Методика в названии
должна соответствовать фактически выполненному вмешательству.

Новые черновики хранятся в scripts/operation-drafts.json; сборщик каталога
добавляет их после извлечённых локальных примеров. Перегенерация не теряет
дополнения. Локальные исходные документы не изменяются.

Контекст для проверки терминологии:
[SAGES — безопасная холецистэктомия](https://www.sages.org/safe-cholecystectomy-program/),
[ASCRS — геморроидэктомия](https://fascrs.org/Web/Patients/Diseases-and-Conditions/A-Z/Hemorrhoids-Expanded-Information.aspx),
[ACS — паховые и бедренные грыжи](https://www.facs.org/for-patients/the-day-of-your-surgery/adult-inguinal-and-femoral-groin-hernia-repair/).

Проверяется выбор каждого нового шаблона и передача его полного текста
в предпросмотр и редактируемый Word-протокол.
