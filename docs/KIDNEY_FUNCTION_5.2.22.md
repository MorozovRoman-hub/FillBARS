# FillBARS Card 5.2.22 — компактный блок функции почек

Поля пола, возраста, массы, креатинина и единицы, строка источника данных и клиническое пояснение теперь находятся внутри раскрывающегося раздела «Исходные данные и ручная проверка». В свернутом виде остаются два результата, кнопка обновления и короткий статус «Данные готовы», «Проверьте данные» или «Загрузка…». Расчёт и источники БАРС не менялись.

Визуальная проверка окна шириной 430 px: свернутый блок занимает около 149 px по высоте. Ручные поля и пояснения остаются доступны по клику на строку раздела.
