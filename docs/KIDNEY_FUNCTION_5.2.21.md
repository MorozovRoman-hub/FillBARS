# FillBARS Card 5.2.21 — креатинин БАРС в ммоль/л

Снимок лабораторной таблицы показал значение креатинина `0,061 ммоль/л`; прежний адаптер принимал только мкмоль/л и мг/дл. Добавлено чтение ммоль/л и точное преобразование `0,061 ммоль/л = 61 мкмоль/л`; расчет CKD‑EPI и Кокрофта—Голта получает одинаковый креатинин независимо от этих двух единиц. Исходное значение и его единица остаются видны и редактируемы в форме.

По снимку главной формы масса уже извлекалась из «Общих сведений». Адаптер теперь сначала проверяет уже открытую лабораторную таблицу и только при отсутствии её данных открывает временную форму. Он также может найти единственную историю болезни, скрытую под модальным окном, не выбирая пациента при нескольких открытых историях. Лабораторная запись без явной единицы по-прежнему не используется для вычислений.

Автоматические тесты охватывают пример лабораторной строки БАРС, преобразование единиц, массу с названием «Вес», открытое лабораторное окно и скрытую под ним историю. Живую проверку результата после обновления расширения должен выполнить пользователь в БАРС.

Основание единиц и формулы: [NIDDK — CKD‑EPI 2021](https://www.niddk.nih.gov/research-funding/research-programs/kidney-clinical-research-epidemiology/laboratory/glomerular-filtration-rate-equations/adults).
