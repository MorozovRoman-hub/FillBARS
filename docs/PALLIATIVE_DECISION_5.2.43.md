# FillBARS 5.2.43 — стандартное решение ВК для паллиативной помощи

По запросу пользователя поле «Решение врачебной комиссии» при открытии бланка паллиативной помощи заполняется текстом: «Признать пациента нуждающимся в оказании паллиативной медицинской помощи.» Текст остаётся редактируемым, его можно заменить либо очистить. Это значение по умолчанию для выбранного шаблона, а не вывод программы по медицинским данным пациента.

Значение задано в метаданных шаблона fieldDefaults. При открытии формы оно заменяет случайное значение одноимённого поля в исходных данных пациента. При экспорте Word используются значения редактора: пользовательские исправления и явно пустое поле имеют приоритет над значением по умолчанию. Исходный образец с чужими данными не возвращается; осмотр, рекомендации и члены комиссии остаются отдельными полями.

Проверка: 22 теста шаблонов и медицинских форм прошли. Проверены начальное стандартное решение, возможность изменения и очистки, безопасная передача текста и сохранность других форм. Браузерная проверка подтвердила наличие решения в предпросмотре и файле, создаваемом кнопкой скачивания. Готовый Word-файл открыт установленным Word и отрисован на одной странице; текст решения присутствует и в Word, и в PDF браузерной печати. Обе страницы просмотрены визуально. Статические проверки пакета и внедрения скриптов пройдены.
