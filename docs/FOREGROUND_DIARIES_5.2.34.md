# FillBARS 5.2.34 — последовательное добавление дневников

Дневники добавляются по одному в открытой карточке БАРС через штатные формы. Скрытые карточки и запуск групп удалены из рабочего пути и пакета расширения. Старый запрос parallel:true игнорируется. Старые неопределённые параллельные очереди по-прежнему требуют ручной проверки перед сбросом.

После сохранения подтверждается новая строка списка осмотров. Дополнительная сверка сохранённого текста выключена по умолчанию и включается в настройках дневников. Результаты различают подтверждение по списку и совпадение всех девяти полей. При включённой сверке расхождения и недоступное чтение останавливают очередь; квитанция сохранённой записи предотвращает повтор.

Причина изменения: в журнале пользователя от 01.11.2026 первые три дневника появились в списке осмотров, после чего очередь остановилась на недоступном повторном чтении. Перед новой отправкой необходимо проверить эти записи в БАРС, чтобы не создать дубли.

Проверка: 199 тестов до последнего теста настройки; затем 64 теста очереди и интерфейса, включая новый тест настройки. Статические проверки структуры пакета и внедрения скриптов пройдены. Новые тесты проверяют последовательность пяти записей, сохранение квитанций перед следующей, остановку во время сохранения, отсутствие скрытого адаптера, явное включение сверки и два добавления без повторного открытия текста. Живые записи пациента для проверки не создавались.
