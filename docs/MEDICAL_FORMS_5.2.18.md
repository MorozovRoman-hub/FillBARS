# FillBARS Card 5.2.18 — печать и новые бланки

- Для согласий на операцию, анестезию, гастроскопию, колоноскопию, бронхоскопию, тромболизис и протокола операции браузерный предпросмотр и печать теперь используют разметку, полученную из тех же исходных Word-бланков, что и скачиваемый DOCX. Печатные страницы проверены в Chrome и Word на синтетических данных. Это не пиксельная копия Word: браузер и Word по-разному рассчитывают переносы при длинном тексте, поэтому перед печатью нужно просмотреть все страницы.
- Для протокола операции область редактирования описания увеличена до 440 пикселей по высоте, редактор стал шире. Переносы строк из описания сохраняются в редактируемом Word-файле.
- В список добавлены формы 315-1/у и 316-1/у, восьмистраничная карта эпидемиологического расследования и двухстраничный протокол катетеризации центральной вены с согласием. Выгружаемые документы сохраняют исходные таблицы и форматирование образцов; образцовые номер карты и дата из катетеризации удалены.
- ФИО, дата рождения, отделение, организация, номер истории, даты лечения и доступные диагнозы подставляются только из соответствующих реквизитов открытой истории БАРС. Для 316-1/у заключительный диагноз берётся из `MKB_FINAL_EXACT`, если поле заполнено. Тяжесть травмы, выводы расследования, параметры катетеризации и подписи остаются ручными.
- Сборка содержит 17 медицинских шаблонов. Автоматические тесты, проверка внедрения скриптов и архивного пакета пройдены; число страниц Word/Chrome для новых форм: 315-1/у — 1, 316-1/у — 1, карта — 8, катетеризация — 2 (Word, браузерная печать по двухстраничной подложке).

Пакет для локальной проверки: `dist/FillBARS-5.2.18-test.zip`. Тестовая папка `C:\projects\заново барс\FillBARS` обновлена из этого архива. После обновления расширения в браузере следует открыть новую форму БАРС и проверить автоподстановку на реальном пациенте без сохранения клинических решений автоматически.
