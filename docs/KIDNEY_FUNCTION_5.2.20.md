# FillBARS Card 5.2.20 — оценка функции почек

На главной форме кнопки листа назначений, заявки на кровь и протокола гемотрансфузии перенесены в выпадающий список «Бланки». На их месте показаны две отдельные оценки:

- СКФ CKD‑EPI 2021, мл/мин/1,73 м²: пол, возраст и сывороточный креатинин. Масса в формулу не входит.
- Клиренс креатинина Кокрофта—Голта, мл/мин: те же данные и масса тела. Это не СКФ, индексированная на 1,73 м².

Данные читаются только для текущей истории болезни. Пол (`PAT_SEX`) и дата рождения (`PAT_BDATE`) берутся из шапки истории, связанной с карточкой пациента; масса — из `DS_CONSITUTION_SPS` формы `ArmPatientsInDep/patients_information`; креатинин с явной единицей — из результатов `DS_ANALYSES` формы `ArmPatientsInDep/Wrappers/analyses`. Временные формы закрываются после чтения. Если поле не найдено, результат не угадывается: в интерфейсе есть ручной ввод. Текст осмотра приёмного отделения автоматически не разбирается — надёжного структурированного поля в найденной форме нет. Источник и дата лабораторного результата показаны пользователю.

Цветовые категории G1–G5 применены только к CKD‑EPI. Это категории уровня СКФ, а не автоматически установленная степень хронической почечной недостаточности. Один результат без признаков поражения почек и наблюдения не подтверждает ХБП; быстро меняющийся креатинин ограничивает применимость расчётов. Для детей до 18 лет оценка не выполняется. Клинические решения остаются за врачом.

Основания: [формула CKD‑EPI 2021](https://www.kidney.org/ckd-epi-creatinine-equation-2021), [категории G1–G5 KDIGO 2024](https://kdigo.org/wp-content/uploads/2024/03/KDIGO-2024-CKD-Guideline.pdf), [формула Кокрофта—Голта и ограничения](https://pubmed.ncbi.nlm.nih.gov/31334948/).

Проверка: контрольные значения NKF, конверсия единиц, уровни G1–G5, парсинг источников БАРС, защита от неполных данных и визуальная проверка главной формы. Живое чтение конкретных данных пациента в БАРС требует ручной проверки в тестовой версии 5.2.20.
