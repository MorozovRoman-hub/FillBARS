# Контрольная точка 5.2.10

## Пользовательский сценарий

Открыть историю болезни → открыть FillBARS → выбрать бланк в списке «Другие бланки». Расширение само получает паспорт, полный адрес, СНИЛС и полис из карточки того же пациента. Открывать карточку и вкладку адресов вручную не требуется. Группа крови автоматически загружается из «Общих сведений».

## Реализация

`patient-details-adapter.js` сверяет AGENT/PERSMEDCARD. Если карточка уже открыта для этого пациента — читает её; иначе создаёт изолированную фоновую среду БАРС по образцу адаптера дневников и открывает `Persmedcard/persmedcard_edit` только для получения сведений. Штатная инициализация карточки выполняет чтение и запись журнала доступа БАРС; кнопки сохранения и действия изменения медицинских данных не вызываются.

Принудительно обновляются только штатные источники чтения `DS_PERSDOCS`, `DS_REAL_ADDRS`, `DS_REG_ADDRS`, `DS_POLIS_OMS`. Источники сверены с `bars/Forms/Agents/subforms_view/*.frm`. Пустой ответ отличён от незавершённой загрузки; смена пациента, ошибка, неоднозначный результат и тайм-аут останавливают чтение. Временные наблюдатели и фоновая среда удаляются в finally. Функции изменения адресного признака и `UPDATE_FULL` не вызываются.

В старом `DControlEvent` БАРС обработчики строкифицируются, поэтому отслеживание результата сделано через временную обёртку `DataSet.setData`, а не callback с потерянным замыканием.

Ограничение версии 5.2.9 о ручном открытии карточки снято. Пять шаблонов и экспорт Word/Excel описаны в [предыдущей контрольной точке](MEDICAL_FORMS_5.2.9.md).
