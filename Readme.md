# FillBARS / МИС БАРС — автоматическое назначение анализов

**FillBARS** — локальное расширение для Chromium/Yandex Browser, которое помогает врачу быстро назначать наборы лабораторных исследований в МИС БАРС и формировать печатный лист назначений.

Версия: **4.3**

## Что умеет расширение

- Выбирать профиль назначений и отмечать нужные анализы в форме БАРС.
- Работать со старыми профилями, где профиль был только набором ID анализов.
- Хранить новый профиль как список анализов, лекарственных назначений и диагностических/режимных процедур.
- Печатать двухстраничный HTML-лист назначений на A4.
- Сохранять локальный журнал назначений без ФИО пациента.
- Импортировать и экспортировать настройки одним JSON-файлом.

Расширение не нажимает финальную кнопку записи в БАРС. Ответственность за назначение остаётся за лечащим врачом.

## Установка

1. Откройте страницу расширений браузера:

```text
browser://extensions
```

2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку проекта, где лежит `manifest.json`.

## Профили назначений

Новая структура профиля:

```json
{
  "analyses": {
    "97829568": true,
    "97830108": true
  },
  "medications": [],
  "procedures": []
}
```

Старые профили вида:

```json
{
  "97829568": true,
  "97830108": true
}
```

автоматически читаются как `analyses`, а при экспорте сохраняются уже в новом формате.

## Как создать профиль с препаратами

1. Откройте popup расширения.
2. Нажмите кнопку с шестерёнкой справа от названия FillBARS.
3. Нажмите «+ Добавить назначение» или «Ред.» у существующего профиля.
4. Во вкладке «Анализы» выберите исследования.
5. Во вкладке «Препараты» найдите препарат в справочнике ЖНВЛП или заполните препарат вручную.
6. Укажите дозу, путь введения, кратность, длительность, режим и комментарий.
7. Нажмите «Добавить препарат в профиль».
8. Во вкладке «Процедуры» добавьте ЭКГ, ЭГДС, УЗИ, колоноскопию, диету, режим или другое назначение.
9. При необходимости измените порядок препаратов и процедур стрелками.
10. Сохраните профиль.

Справочник `drug-catalog-zhvnlp-2025.json` используется только для выбора названия, АТХ, группы и лекарственной формы. Дозу, кратность, путь введения и длительность врач указывает сам.

Если препарата нет в справочнике, его можно добавить вручную и сохранить в пользовательский справочник. Пользовательский справочник хранится локально в браузере и попадает в экспорт настроек.

## Как назначать анализы в БАРС

1. Откройте форму назначения анализов в МИС БАРС.
2. Убедитесь, что отображаются все нужные исследования.
3. В popup выберите профиль.
4. Нажмите «Заполнить форму БАРС».

Для старой логики БАРС используется только часть профиля `analyses`. Препараты и процедуры не передаются на страницу БАРС и нужны для печатного листа и журнала.

## Как печатать лист назначений

1. В popup выберите профиль назначений.
2. При необходимости измените дату назначения.
3. Оставьте активной страницу пациента в МИС БАРС.
4. Нажмите «Открыть лист назначений».
5. Расширение автоматически прочитает ФИО и дату рождения из активной страницы БАРС и откроет HTML-бланк в отдельной вкладке.
6. Нажмите «Печать».

Печатная форма:

- формат A4 landscape;
- страница 1: «ЛИСТ НАЗНАЧЕНИЙ И ИХ ВЫПОЛНЕНИЕ» с лекарственными назначениями и лечебным питанием;
- шапка страницы содержит пустые поля диагноза, аллергии, номера палаты и номера истории болезни;
- страница 2: оборотная сторона с таблицей «Медицинское вмешательство»: сначала назначенные анализы, затем диагностические и режимные процедуры;
- кнопки печати и закрытия скрываются при печати.

## Локальное хранение

Постоянно хранятся:

- профили;
- анализы в профилях;
- препараты в профилях;
- диагностические, режимные и иные назначения в профилях;
- каталог анализов;
- пользовательский справочник препаратов;
- настройки расширения.

Временный журнал назначений хранится в IndexedDB до 60 дней.

В журнал сохраняются:

- технический ID записи;
- дата создания записи;
- выбранный профиль;
- список лекарственных назначений;
- список процедур и режимных назначений;
- список анализов.

В `fillbars-config.json` добавлены заполненные шаблоны на основании файла `профиля.txt`:

- острый тромбофлебит;
- острый панкреатит;
- острый аппендицит;
- ректальное кровотечение;
- желудочно-кишечное кровотечение.

В журнал не сохраняются:

- ФИО пациента;
- дата рождения.

Автоочистка выполняется при каждом запуске popup: записи старше срока хранения удаляются. В настройках есть кнопка «Очистить журнал сейчас».

## Импорт и экспорт

Кнопка «Экспорт настроек» сохраняет:

- профили в новой структуре;
- активные профили;
- настройки сценария БАРС;
- настройки журнала;
- каталог анализов;
- пользовательский справочник препаратов.

Кнопка «Импорт настроек» загружает JSON обратно в расширение.

## Безопасность

Расширение не отправляет данные на внешние серверы и не подключает внешние библиотеки через CDN. Данные обрабатываются локально внутри браузера.
