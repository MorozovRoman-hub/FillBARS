# 🏥 МИС БАРС — Автоматическое назначение анализов

**FillBars** — это мощное расширение для Яндекс.Браузера и других Chromium-браузеров, которое полностью преображает работу с лабораторными исследованиями в **МИС БАРС**. Оно позволяет назначать готовые наборы анализов в один клик, а также может автоматизировать выбор кабинета и отметку срочности в окне записи.

✨ **Текущая версия: 3.0**

---

## 🚀 Основные возможности

| Функция | Описание |
| :--- | :--- |
| ⚡ **Мгновенное назначение** | Выбирайте профиль и все нужные анализы отмечены. Больше никакой рутины. |
| 🗂️ **Профили "под себя"** | Создавайте, редактируйте и удаляйте свои наборы исследований прямо в интерфейсе расширения. |
| 🤖 **Умная автоматизация** | Расширение само пытается открыть раздел **«Все исследования»** и выставить **150 записей** для показа полного списка. |
| ⚙️ **Гибкий сценарий** | Можно остановиться после выбора анализов или продолжить: нажать «Назначить», выбрать кабинет и отметить срочность. |
| 💾 **Перенос настроек** | Экспортируйте и импортируйте все свои профили и настройки одним файлом (`fillbars-config.json`). |
| 🔒 **Локальное хранение** | Все данные (профили, настройки, каталог анализов) хранятся только в вашем браузере и никуда не передаются. |

## 🎯 Как это работает

### 📝 Этапы выполнения

В настройках расширения есть переключатель **«Этап выполнения»**:

1.  **Только анализы:** Быстрый режим. Расширение отмечает нужные чекбоксы и останавливается. Кнопка «Назначить» не нажимается.
2.  **Кабинеты и срочно:** Полный режим.
    *   Отмечает исследования.
    *   Нажимает «Назначить».
    *   В открывшемся окне подбора времени выбирает для каждой строки указанный вами кабинет.
    *   Ставит галочку **«Срочно»** (если включено в настройках).

    > **Важно:** Финальную кнопку записи (например, «Записать») расширение не нажимает, оставляя последнее слово за врачом.

### 🛠️ Создание своих профилей

Встроенный редактор позволяет гибко настраивать ваши наборы исследований:

1.  Нажмите на иконку **«⚙️» (Настройки)** в окне расширения.
2.  Выберите существующий профиль для редактирования или нажмите **«+ Добавить назначение»**.
3  Выберите иконку и придумайте название для профиля.
4.  Нажмите **«Обновить список»**, чтобы расширение считало актуальный список анализов с открытой страницы МИС БАРС.
5.  Отметьте нужные исследования из списка и сохраните профиль.
